# 🚨 AI Emergency Helper — Prototype

AI Emergency Helper is an AI-powered prototype application that provides real-time first aid guidance during emergency situations using Google Gemini.

The system allows users to describe an emergency scenario and instantly receive step-by-step instructions, safety precautions, and recommendations on when to contact emergency services.

This prototype was developed using **Google AI Studio** to validate the concept before implementing the full Android mobile application using Kotlin.

---

## 🌟 Features

- 🤖 AI-powered emergency assistance
- 🚑 Step-by-step first aid instructions
- ⚠️ Safety tips and precautions
- ❌ What to avoid during emergencies
- 📞 Emergency contact recommendations
- 📊 Severity level classification (Low / Medium / High)
- 🎨 Clean and responsive user interface

---

## 🧠 Technologies Used

- React (TypeScript)
- Tailwind CSS
- Google Gemini API
- Google AI Studio
- Lucide Icons

---

## ⚙️ How It Works

1. User describes the emergency situation.
2. The input is sent to the Gemini AI model.
3. AI analyzes the situation and generates structured first aid guidance.
4. The results are displayed in a user-friendly interface.

---

## 🚀 Run Locally

**Prerequisites:** Node.js installed

2. Create a file named `.env.local` in the project root and add:

GEMINI_API_KEY=YOUR_API_KEY_HERE


3. Run the application
